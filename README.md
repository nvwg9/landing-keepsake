# Keepsake – адаптивний лендінг

Односторінковий лендінг дизайн-агенції Keepsake, зверстаний за макетом «Keepsake - Responsive» (фрейми Desktop 1280, Tablet 768, Mobile 375, Mobile menu open, UI states).

Демо: https://nvwg9.github.io/landing-keepsake/

## Технології

- HTML5 з семантичною розміткою: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`, `form`.
- CSS без фреймворків і UI-бібліотек. Власний reset на початку `css/style.css`.
- Шрифти Oswald, Open Sans і Dancing Script з Google Fonts з `display=swap`.
- Іконки – інлайн-SVG у спрайті (`<symbol>` + `<use>`).
- Зображення у WebP з `width`, `height` і `loading="lazy"`.

## Рішення

- **CSS-змінні.** Кольори, шрифти, розміри шрифтів, поля контейнера й відступи секцій оголошені в `:root`. На брейкпоінтах змінюються лише значення змінних.
- **Mobile first.** Базові стилі написані для 375 px, далі `@media (min-width: 768px)` і `@media (min-width: 1280px)`. На ширині понад 1280 контейнер центрується з максимальною шириною 1100 px.
- **Розкладка.** Секції побудовані на Flexbox, сітка робіт – на CSS Grid (1 / 2 / 3 колонки, 5 / 8 / 9 карточок). Пропорції карточок задані через `aspect-ratio`.
- **Мобільне меню без JS.** Меню – елемент з атрибутом `popover`, бургер – `<button popovertarget>`. Браузер сам відкриває й закриває меню та передає стан `aria-expanded` допоміжним технологіям. Хрестик усередині меню закриває його (`popovertargetaction="hide"`), так само працює клавіша Esc.
- **Фільтр портфоліо.** Приховані радіокнопки і чипси-`label`. Селектор `:checked ~` підсвічує активний чипс і ховає карточки з іншим `data-category`. Фільтр працює з клавіатури (стрілки), фокус видно на чипсі.
- **Ховер карточки.** Оверлей, бірюзове коло з «+», назва, коралова лінія й категорія. Той самий стан вмикається на `:focus-visible`.
- **Форма підписки.** HTML-валідація email і обов'язковий прапорець. Фокус – бірюзовий бордер, помилка – кораловий бордер і текст через `:user-invalid` (текст пов'язаний з полем через `aria-describedby`). Після відправки адреса отримує `#subscribed`, і через `:target` замість полів показується повідомлення про успіх.
- **Fixed header** і кнопка «вгору» 44×44, відступ під шапку через `scroll-padding-top`.
- **Доступність.** Усі інтерактивні елементи доступні з клавіатури, у іконочних кнопок є `aria-label`, у полів форми – `label`, декоративні зображення мають `alt=""`. Враховано `prefers-reduced-motion`.
